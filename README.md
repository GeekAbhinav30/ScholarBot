ScholarBot: Research Paper Q&A Assistant

This project uses Open-LLaMA 3B + RAG to answer questions from research papers.

Features:
- PDF upload
- Research paper Q&A
- FAISS vector database
- Gradio interface

Model Loading:
The model is loaded either:
- from Google Drive
- or directly from HuggingFace

Run:
Open notebook.ipynb in Google Colab and run all cells.
